# Rust `no_std` Wasm plugin example

This is a bare-bones Typst plugin, written in [`no_std`](https://doc.rust-lang.org/stable/std/attribute.no_std.html) Rust.

This example is merely for illustration purposes. In most cases, you should refer to the [`hello_rust`](../hello_rust/) example and use `std` Rust instead. Using `no_std` Rust to develop a Typst plugin is more difficult than using `std` Rust, and there is no known benefit to doing so.

The compilation steps for this example are omitted, as they are exactly the same as those in [`hello_rust`](../hello_rust/).
